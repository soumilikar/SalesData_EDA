# SalesData_EDA
Analyzing apparel store sales data to improve customer experience and sales.

Dataset used: shopping_trends.csv from Kaggle
Python Libraries used: numpy, pandas, matplotlib and seaborn

## Exploratory Data Analysis of Apparel Store Data:

1) Cleaned and preprocessed data (including adding a new column for age range for easy demographic understanding) using Pandas library.
2) Conducted univariate and bivariate analysis across demographic parameters (gender, age group, state, apparel sizes and catagories) to identify key revenue-driving segments
3) Built interactive static visualizations using Matplotlib and Seaborn to track purchasing trends across 50+ states.
4) Concluded that: American men in age group 18-30 years from Illinois, Montana and California are more likely to buy 'M' size clothing items (namely blouses and pants) from our apparel chain.
