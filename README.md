# SalesData_EDA
Analyzing apparel store sales data to improve customer experience and sales.

Dataset used: shopping_trends.csv from Kaggle

## Exploratory Data Analysis of Apparel Store Data:

> Cleaned and preprocessed data (including adding a new column for age range for easy demographic understanding) using Pandas
> Conducted univariate and bivariate analysis across demographic parameters (gender, age group, state, apparel sizes and catagories) to identify key revenue-driving segments
> Built interactive static visualizations using Matplotlib and Seaborn to track purchasing trends across 50+ states.
> Concluded that: American men in age group 18-30 years from Illinois, Montana and California are more likely to buy 'M' size clothing items (namely blouses and pants) from our apparel chain.
